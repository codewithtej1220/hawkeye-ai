SAHI stands for **Slicing Aided Hyper Inference** - a technique that dramatically
improves detection of small objects like weapons in thermal images.

================================================================================
THE PROBLEM (20 seconds)
================================================================================

Standard YOLOv11m was giving us only **65% weapon detection accuracy**.

**Why?**
- Weapons are TINY in thermal images: 20-40 pixels
- YOLO downsamples input to 640×640
- After downsampling: weapons become 15×25 pixels
- Network loses spatial detail at this small resolution
- Many weapons missed or below confidence threshold

**This was unacceptable for a security system!**

================================================================================
THE SOLUTION: SAHI (45 seconds)
================================================================================

**SAHI Algorithm:**

Instead of processing the full image at once, SAHI:

1. **Slices** the image into smaller overlapping tiles
   - Input: 640×480 thermal image
   - Tile size: 512×512 pixels
   - Overlap: 30% (154 pixels)
   - Result: 4 overlapping tiles

2. **Runs inference** on EACH tile separately
   - Each tile processed by YOLOv11m independently
   - Weapons stay FULL SIZE in each tile (25×40px, not 15×25px)
   - No downsampling loss

3. **Merges predictions** from all tiles
   - Collect all detections from all 4 tiles
   - Apply Non-Maximum Suppression (NMS)
   - Use IOS metric (Intersection Over Smaller)
   - Keep highest confidence when boxes overlap >50%

**Why 30% Overlap?**
- Ensures objects at tile boundaries are captured in BOTH adjacent tiles
- Prevents missing objects that span tile edges
- Tested 10%, 20%, 30%, 40% → 30% gave best accuracy/speed trade-off

================================================================================
KEY OPTIMIZATIONS (30 seconds)
================================================================================

**1. Confidence Threshold Tuning**
- Standard YOLO: 0.35 confidence
- SAHI for weapons: 0.20 confidence (lowered)
- Reason: Small weapons have lower confidence scores
- Result: +13% weapon recall improvement

**2. NMS with IOS Metric**
- Standard NMS uses IoU (Intersection over Union)
- SAHI uses IOS (Intersection Over Smaller)
- IOS = Intersection / min(box1_area, box2_area)
- Better for handling boxes at tile boundaries
- Match threshold: 0.5

**3. Tile Overlap Optimization**
- Increased from 20% → 30%
- Prevents missing objects at edges
- Added +4% recall improvement
