================================================================================
THE ML CHALLENGE (30 seconds)
================================================================================

We faced THREE critical ML challenges:

1. **NO Existing Dataset**: No public thermal weapon dataset existed
2. **Severe Class Imbalance**: 2.7:1 ratio (1,200 human vs 450 weapon boxes)
3. **Small Object Detection**: Weapons are tiny (20-40 pixels) in thermal images

Standard YOLO was achieving only 65% weapon detection - unacceptable for 
security applications.

================================================================================
DATASET CREATION (45 seconds)
================================================================================

I created the HawkEye Thermal Threat Dataset from scratch:

**Three Sources:**
1. **RGB Dataset**: 214 images (204 train, 10 test)
   - Classes: RGB, person, weapon
   - Used for human detection training

2. **Thermal Dataset**: 215 images (205 train, 10 test)
   - Classes: thermal, person, weapon  
   - 51 weapon annotations (76% MORE than RGB!)
   - Used for weapon detection training

3. **HawkEye Test Set**: 5 AirSim thermal images
   - Real simulation scenarios: sprint, aiming, running, walking, crouching

**Total**: 429 images, 1,650+ manual annotations (40 hours of work)

**Data Augmentation** to handle class imbalance:
- Horizontal flip (50%), rotation (±15°)
- Brightness (±20%), contrast (±15%)
- Mosaic augmentation (4-image tiles)
- **Weighted Loss**: 2.5x penalty for weapon misclassification

================================================================================
SAHI INTEGRATION (45 seconds)
================================================================================

**The Problem**: Standard YOLO gave only 65% weapon detection

**The Solution**: SAHI (Slicing Aided Hyper Inference)

**How SAHI Works:**
1. Slice 640×480 image into 512×512 tiles (30% overlap)
2. Run YOLOv11m on EACH tile separately  
3. Merge predictions using NMS with IOS metric

**Why It Works**:
- Weapons stay FULL SIZE in each tile
- No downsampling loss of detail
- Network sees weapon as 25×40px (not 15×25px)

**Key Optimizations**:
- Lowered confidence: 0.35 → 0.20 (+13% recall)
- Increased overlap: 20% → 30% (+4% recall)
- NMS with IOS metric (eliminates duplicates)

**Result**: 65% → 85% weapon detection (+20% improvement!)

**Trade-off**: +107ms latency, but WORTH IT for 20% accuracy gain

================================================================================
THREAT CLASSIFICATION (30 seconds)
================================================================================

**4-Level Intelligent Threat Assessment:**

```
Algorithm:
1. Detect humans (RGB model)
2. Detect weapons (Thermal model)
3. Associate weapons to humans (35% bbox expansion)
4. Determine threat level:
   - CLEAR: No humans (risk score 0)
   - ELEVATED: Humans, no weapons (risk score 2)
   - HIGH: 1 armed person (risk score 5)
   - CRITICAL: 2+ armed (risk score 10)
```

**Weapon-Person Association**:
- Expand human bbox by 35%
- Check if weapon center falls inside
- Update armed flag + weapon_count

**Accuracy**: 92.5% threat classification (74/80 test images)
