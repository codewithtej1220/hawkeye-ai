================================================================================
                    PROJECT WORKFLOW - HAWKEYE AI
          (End-to-End Pipeline: Simulation → Detection → Dashboard)
================================================================================

OVERVIEW:
---------
HawkEye AI is a 4-tier distributed system that captures thermal drone imagery,
detects humans and weapons using AI, and streams results to a live dashboard.

Total Development Time: 12 weeks (Hybrid Waterfall-Agile)
Team: 4 members (ML, Backend, Frontend, Simulation/Integration)

================================================================================
PHASE 1: ARCHITECTURE DESIGN (Waterfall - 2 weeks)
================================================================================

Week 1-2: Requirements & System Design
--------------------------------------
✓ Defined 10 functional requirements (FR1-FR10)
✓ Defined 5 non-functional requirements (Performance, Accuracy, Reliability)
✓ Selected 4-tier architecture: Simulation → Capture → Backend → Frontend
✓ Technology stack selection: AirSim, YOLOv11m, FastAPI, React
✓ API specification: POST /detect, WebSocket /stream

Key Decisions:
- Simulation-based (v1.0): No physical drone deployment
- Thermal imaging: Illumination-independent detection
- Real-time: <300ms end-to-end latency requirement
- SAHI integration: For small weapon detection

- Low weapon accuracy (65%) → Lowered confidence 0.35→0.20 (+13%)

================================================================================
COMPLETE DATA FLOW (265ms end-to-end)
================================================================================

STEP 1: Thermal Generation (20ms)
----------------------------------
Unreal Engine renders ForestSim scene
↓
AirSim generates thermal segmentation (640×480)
↓
Distance transform + COLORMAP_JET + Gaussian blur
↓
JPEG output at 1 FPS

STEP 2: Image Transmission (10ms)
----------------------------------
Python capture script (integrated_capture.py)
↓
NumPy array → JPEG encode (quality 85%)
↓
Base64 encoding
↓
HTTP POST → http://localhost:8000/detect

STEP 3: AI Detection Pipeline (152ms)
--------------------------------------
FastAPI receives POST /detect
↓
Base64 decode → NumPy array (cv2.imdecode)
↓
BGR → RGB conversion
↓
SAHI Slicing (512×512, 30% overlap) → 4 tiles
↓
YOLOv11m inference on each tile:
  - RGB model: Human detection
  - Thermal model: Weapon detection
↓
NMS merge (IOS metric, threshold 0.5)
↓
Classification: person vs weapon labels
↓
Weapon-person association (35% bbox expansion)
↓
Threat level determination:
  - No humans: CLEAR (risk score 0)
  - Humans, no weapons: ELEVATED (risk score 2)
  - 1 armed person: HIGH (risk score 5)
  - 2+ armed: CRITICAL (risk score 10)

STEP 4: Annotation (30ms)
--------------------------
Copy original image
↓
Draw bounding boxes:
  - Green (2px) for humans + "HUMAN" label
  - Red (2px) for weapons + "WEAPON" label
↓
Base64 JPEG encode (original + annotated)

STEP 5: Broadcasting (5ms)
---------------------------
Package JSON payload:
{
  "frame_id": 12345,
  "timestamp": "2026-06-10T20:30:15Z",
  "image": "data:image/jpeg;base64,...",
  "annotated_image": "data:image/jpeg;base64,...",
  "detections": [...],
  "summary": {
    "level": "HIGH",
    "total_people": 1,
    "armed_people": 1,
    "weapon_count": 1,
    "risk_score": 5
  }
}
↓
WebSocket broadcast to all clients (/stream)

STEP 6: Visualization (35ms)
-----------------------------
React frontend receives WebSocket message
↓
Parse JSON → Update React state (useState)
↓
Left panel: Original thermal image
↓
Right panel: Annotated image with boxes
↓
Threat indicator: Update badge color + text
↓
Metrics refresh: People count, weapons, confidence
↓
Archive: Add new entry (50 rolling window)
